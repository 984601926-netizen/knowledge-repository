# 拾知 · 林间学园 2.0

游戏化个人知识库首版。保留原知识库的资料管理能力，加入森林家园、文字老师、主动讲解、间隔复习、专注记录和好友做客。

## 安装与开始

运行 `release/Shizhi-Setup-2.0.0.exe`。旧版先保存并退出，再覆盖安装，无需卸载。也可以直接运行 `release/win-unpacked/拾知.exe`，该目录内的所有文件需要一起保留。

首次打开赠送两颗种子。点击地面，或使用 `A/D`、左右方向键移动；走近交互点按 `E`。点击交互点也会先走近，再进入功能。上方导航提供快捷入口。

- 小屋里的**书架**管理资料，**书桌**进入学习工作台。
- **种子袋**选择种子后，点击花园地面种下；点击植物可照料或重新摆放。
- 屋外有种子商店和扭蛋机。扭蛋与学习奖励需要亲手打开揭晓。
- 首版提供六种原创观赏植物、室内外场景、行走及坐下阅读的角色素材。

## 资料、学习和复习

书架支持 PDF、EPUB、Word、Markdown 和常见图片。导入文件复制进知识库，原文件移动后仍可使用。单文件上限 200 MB，Markdown 上限 10 MB，一批最多 500 个文件。EPUB 只接受可解析、无 DRM 的书籍，解压总量限制 80 MB。

文件夹负责分类，标签辅助筛选。保留笔记可视化编辑、中文搜索、收藏、回收站、Markdown 与图片资源导出，以及可调整的三栏布局。搜索覆盖标题、笔记、备注、标签、已索引的 PDF 和 EPUB 文字。Word 保存原件，点击后调用外部 Word，不在首版解析正文。

在书架选择资料，点击**在书桌学习**：

1. 中间阅读 PDF 或 EPUB，按需展开大纲、知识点记录和老师。
2. PDF 有目录时提取目录，否则以页码定位；EPUB 按章节阅读。书架分别显示阅读位置和已掌握知识点数量。
3. 提问答疑，或让老师梳理当前章节/对话。超长章节使用受限的原文片段，不能视为逐字覆盖全书。
4. 新知识点自动保存为草稿，可以修改、丢弃或确认。确认后进入统一复习中心，支持分级结构。
5. 选择知识点，回答它的问题，向老师讲解自己的理解。

老师先给出 1—100 分，再简洁指出错误、遗漏和下一步建议。**掌握由能否准确讲解决定，不设及格分数线。**解释原理和应用可自行继续讨论。对话长期保存，输入草稿在本机保留；网络失败或取消请求后可以重试。资料答疑提供实际送入模型的原文出处，点击可定位并查看摘录。引用定位不等于模型结论已经得到人工核实。

老师配置位于右上角齿轮：填写兼容 Chat Completions 的 API 地址、模型名称及自己的 Key。本机免密服务可不填 Key。远程地址使用 HTTPS，本机 localhost 可用 HTTP。实际模型效果、速度与费用由所选服务决定；未配置时不会伪造老师回答。

复习中心支持自主练习和到期推荐，采用间隔复习表作为艾宾浩斯方向的首版实现，并非对每个人遗忘情况的精确预测。复习未通过，状态变为**待巩固**；提前练习不会提前刷新奖励领取时间。

## 首版默认规则

未指定的数值集中在 `electron/habitat.mjs` 的 `RULES` 和 `SPECIES`，后续可以统一调整。

| 项目                   | 默认行为                                                                |
| ---------------------- | ----------------------------------------------------------------------- |
| 首次准确掌握知识点     | 神秘种子 1 颗、金币 10；同一知识点不重复领取首次奖励                    |
| 到期复习通过           | 水 1、肥料 1、金币 5；提前练习不发放复习奖励                            |
| 成功复习后的下一段间隔 | 依次为 1、2、4、7、15、30、60 天；首次掌握后为 1 天                     |
| 专注种子               | 同一段专注每累计 45 分钟有效运行时间，有 20% 概率获得一颗；暂停不计时   |
| 阅读中的种子           | 累计阅读至少 60 秒后，每份资料每个本地自然日最多一次 15% 概率的发现机会 |
| 扭蛋                   | 20 金币一次，六个品种等概率，神秘种子成长后揭晓                         |
| 生长                   | 六个品种分别需要约 2—5 个现实日；施肥增加 12 小时生长进度               |
| 日常照料               | 浇水消耗 1 水，施肥消耗 1 肥料，修剪免费；同一操作间隔 12 小时          |
| 枯死                   | 连续 7 个现实日未照料会永久枯死；修改系统时间不能使已枯死植物复活       |

专注计时可以独立开启，并关联资料或学习主题。页面提供历史记录和按资料/主题聚合的时间分布。关闭软件前保存进行中的计时；重新打开后保持暂停，关机、系统休眠和程序关闭期间不补计专注时间。突然断电可能丢失最后约 15 秒尚未落盘的专注增量。时间记录显示最近 500 段，分布统计查询全部历史。

## 好友与共享自习

无需注册，软件生成本机身份和好友码。**好友功能需要双方连接同一个自习服务；未代为部署公共服务器。**

局域网使用：

1. 一人在“好友”页面点击**启动局域网自习服务**。
2. 将本机局域网服务地址（例如 `ws://192.168.1.20:47831`）给好友；对方填入地址并连接。必要时允许 Windows 防火墙的专用网络访问。
3. 交换好友码，发送并接受好友请求。
4. 主人邀请好友来家中；对方接受后进入共享家园，查看彼此角色、在线状态与专注计时。

好友做客时可查看公开资料和正式知识点。PDF、EPUB、长笔记及笔记插图使用分块读取；Word 共享原文件，访客保存后用外部程序阅读。共享目录支持搜索和分页。

**资料和知识点默认好友可见。**可以单独设为私密；私密资料的现有及新生成知识点、相关学习对话也保持私密。把原资料重新公开，不会自动公开此前设为私密的衍生内容。每次请求和文件分块都会重新检查访问资格及隐私状态。API 配置、密钥和完整学习对话不向好友提供。

公网使用需要自己部署同一套中继服务并提供可达地址，可通过反向代理配置 WSS。已安装程序支持 `--relay-server --port=47831` 参数，可作为不显示窗口的服务进程启动。

服务使用设备签名验证身份，转发在线状态、邀请和已授权的共享数据，不写入个人资料数据库。服务端基于 [ws](https://github.com/websockets/ws)。同一身份只允许一台设备同时连接同一个服务。好友文字聊天、代浇水和公开自习大厅暂不包含在首版。

## 保存、备份与升级

个人资料保存在 `%APPDATA%/zhishi-local/library`。准确位置在书架左下角“设置 → 通用”查看。可通过命令行 `--library=D:\我的知识库` 指定其他目录。

- 笔记自动保存，默认停笔约 1 秒，也可 `Ctrl+S`。失败时保留编辑内容并阻止正常关闭。
- 自动备份在本地自然日首次启动时生成，保留最近 7 份。
- 书架左下角“设置 → 备份与恢复”支持自定义备份目录、手动完整备份和恢复。
- 完整 `.szkb` 备份包含资料原件、笔记图片、标签、文件夹、家园、设备身份、学习对话、知识点、复习进度和已保存专注记录。
- 恢复前校验清单、文件哈希、数据库与关联结构，并备份当前库；无效备份不会替换当前库。
- 密钥使用系统凭据加密，位于知识库目录旁的 `library-ai.json`，不随备份导出，换设备后重新填写。个人偏好和备份目录也保持本机设置。
- 从旧版首次打开时先生成 `before-habitat-*.szkb`，再升级到数据格式 3。升级后不要用旧版直接打开；回退请使用升级前备份。
- 回收站适用于资料，永久删除需确认。永久删除原资料后，已沉淀的知识点与学习对话保留，原文引用可能无法继续跳转。

SQLite 采用事务、同步与原子替换，保留前一次完整保存和恢复日志。完整备份当前限制 512 MB；未发送文字草稿不属于完整备份。永久删除后部分附件仍可能保留，以支持前一份数据库恢复和共享图片引用。

## 源码与交付

保留 `src/`、`electron/`、`public/art/`、`build/`、开发脚本、配置和依赖锁文件。美术素材及生成提示词见 [ASSETS.md](ASSETS.md)。素材通过内置图像工具生成，图像已复制进项目，运行不依赖聊天附件或远程图片。

测试在独立临时知识库和本地协议服务执行。按要求，交付前删除测试代码、测试资料、截图、构建缓存和开发依赖目录，保留安装包、完整便携运行目录及源码。

维护需要 Node.js 24：

```powershell
npm ci
npm run dev
npm run build
npm run dist
```

Electron、NSIS 首次构建需要下载依赖；已有本地 Electron 分发时可用：

```powershell
npx electron-builder --win nsis --x64 --config.electronDist=node_modules/electron/dist
```

个人知识库、植物园和专注记录可以离线使用；远程老师与好友需要网络。首版不包含云同步、语音、OCR、Office 正文解析、PDF 高亮批注或移动端。
